SPM 2026 STEM B Countdown — installable website bundle

Files:
- index.html: countdown website
- manifest.webmanifest: app name, display mode and theme
- icon.svg: home-screen/app icon
- sw.js: offline cache service worker

IMPORTANT: The Install app feature cannot be fully enabled by opening index.html directly as a file. Browsers require a secure HTTPS website (localhost is allowed for testing) for PWA installation and service workers.

Quick publishing options:
1. Upload these files together to a static hosting service that provides HTTPS (for example GitHub Pages or Netlify).
2. Open the resulting HTTPS address on your phone in Chrome, Samsung Internet, Edge or Safari.
3. Tap Install app if the browser offers it. Otherwise open the browser menu and choose Install app / Add to Home Screen. On iPhone/iPad, use Safari > Share > Add to Home Screen.

The logo uses a clean rounded green gradient inspired by modern One UI-style icon design; it is an original icon, not an official Samsung logo.
